# 补给线 · 主体

纯前端竖屏挂机。游戏定名 **补给线**（仓库名 `idea7_supplyline`）。工程对齐 sibling 库 idea5_idle：Vue3 + TypeScript + Vite + Pinia + Vitest，`src/sim` 纯逻辑，`src/ui` 薄门面。GitHub Pages 为 project site，Vite `base` 为 `/idea7_supplyline/`，在线地址 https://sung1011.github.io/idea7_supplyline/ ，推 `main` 即部署。存档键名 **`idea7Supplyline`**。

当前仓库只有可运行骨架，**不实现玩法**。方向对齐医院 + 餐厅：

- **医院**：收治前线伤员，负责恢复与床位周转。
- **餐厅**：生产伙食，把热食和补给送到前线。

后勤线把两者串起来：餐厅出餐、医院收治，为前线战士做后勤补给。玩法细则后续再写。
