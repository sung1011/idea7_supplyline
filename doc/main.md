# 补给线 · 主策划

独立新游《补给线》（Supplyline / Resupply）的主策划文档。本文只写**已拍板**的定位、视觉、区域、主循环与补给玩法；战斗数值、工人合玩法等另议内容见文末「待定」，不在本文展开。

**库名：** `idea7_supplyline`  
**文档角色：** 后续医院、餐厅、后厨落地的唯一主依据。实现与本文冲突时，以本文为准并回头改文档。

**工程基线（骨架已在仓库，玩法按本文，产品不从属于 idle）：** 纯前端。技术栈对齐 sibling 库 `idea5_idle`：Vue3 + TypeScript + Vite + Pinia + Vitest；`src/sim` 纯逻辑，`src/ui` 薄门面。GitHub Pages 为 project site，Vite `base` 为 `/idea7_supplyline/`，在线地址 https://sung1011.github.io/idea7_supplyline/ ，推 `main` 即部署。存档键名 `idea7Supplyline`。

## 1. 定位

《补给线》是一款**独立新游**，不是 `idea5_idle` 的子系统、资料片或皮肤换皮。仓库、循环、数值、美术全部单独立项。

玩家扮演后勤侧：为前线战士做补给，先做**食物**和**医疗**，后续可扩**装备**。乐趣不在亲自冲锋，而在把人派出去、把伤病饿乏接回来、把饭和药做对、再把人送回营地待命。

一句话：

> 营地派人出战 / 上工 → 打完进医院、体力见底进餐厅 → 补给完成回营地。

---

## 2. 视觉

**对标：** Clash Royale / 皇室战争的极卡通，不是现代战争写实。

必须做到：

- 大头、圆润、短肢，角色可读性靠剪影和头身比，不靠迷彩与枪械细节。圆形大头要有盔/帽体积高光、眉、腮红、下巴弧和肩领。
- 粗描边、色块清楚、高饱和；医院偏暖红/白、餐厅偏暖黄、营地偏草绿/帐篷色，区域一眼可分。
- 壳是厚塑料玩具感：板子内缘高光 + 轻内阴影，按钮顶 1px 高光条与厚底边；纹理只用纯渐变，不加噪点。
- 战场、伤员、药剂都卡通化：红十字、蒸汽、爱心、星星 buff，不要血沫、断肢、写实绷带特写。

明确不做：现代迷彩、夜视、弹孔、纪实摄影风、灰绿写实军营。

## 3. 区域

全游戏按功能拆成四类空间。营地是主区域；医院和餐厅是补给区域；工坊是有限派工点，不再是挂机无限产线。

### 3.1 营地（主区域）

- **独立主区域**，不是医院/餐厅的附属 UI。
- 核心是**待命区**：人空闲时站在这里，等玩家派工或出战。
- 玩家从营地把人派出去：
  - **出战**：去战斗，打完（通常带伤）进医院。
  - **上工**：去工坊等有限任务，做完回营地；体力耗尽则进餐厅（补给），不在工位上无限挂着。
- 医院出院、餐厅吃完，人都回到营地待命，再进入下一轮派遣。

### 3.2 医院、餐厅（补给区域）

- 医院解决**血量**；餐厅解决**体力 / 进食订单**（菜也可附带回血与短效 buff，但回血不是餐厅主职）。
- 两处都从营地「流入」，补给完成后「流回」营地。
- 容量可扩充（床位、餐桌），扩容前用排队消化溢出。

### 3.3 工坊（有限派工）

相对旧挂机思路，本游戏明确取消：

- 自动无限上工
- 人永远停在工位产出

改为：

- **有限派工**：一次任务有完成条件，做完即停。
- 人做完回营地待命。
- 若体力在任务中耗尽，进入补给（餐厅），不在工坊里硬撑。

工坊具体配方、工种、产出数值另议；本文只锁「有限、做完就停、回营地或进补给」。

## 4. 主循环

```
          ┌──────────── 营地（待命） ────────────┐
          │                │                    │
          │              出战                  上工
          │                │                    │
          │             战斗中                 工坊中
          │                │                    │
          │           打完（带伤）          做完 / 体力见底
          │                │                    │
          │              医院                  餐厅
          │           占床回血              点餐 → 上菜
          │           满血离院              补给完成
          │                │                    │
          └────────────────┴────────────────────┘
                           回营地待命
```

三条铁规则：

1. **派遣只从营地发生**（出战、上工）。
2. **医院吃伤、餐厅吃饿（体力）**；不要让工坊或战场兼做完整补给。
3. **补给完成必须回营地**，再决定下一趟，禁止补给区直接连去下一场战斗或下一单无限工。

## 5. 医院

医院是伤员回血的补给区。目标体验：床位是瓶颈，药剂是加速，没床就排队，满血立刻走人。

### 5.1 床位

- 床位可扩充。未扩容前，床是硬上限。
- **占床**才缓慢回血；没占到床的人**排队等床**，排队本身不回血（或回得极慢——具体曲线待定，默认：排队不回血）。
- 有人满血离院 → 空床立即分给队首。

### 5.2 回血与药剂

- 占床 = 时间换血量，基础速度慢，让「床位数」和「伤员通量」成为经营压力。
- **药剂加快**占床回血，不替代床位：没床不能靠砸药原地满血。
- 药剂来源、合成、消耗数值待定；规则已定：药是加速器，床是资格。

### 5.3 离院

- **满血离院**，回营地待命。
- 不要在医院里做出战、上工入口；医院只出、不派。

### 5.4 医院已定 / 未定

| 已定 | 未定 |
| --- | --- |
| 床位可扩、占床慢回血、药剂加速、无床排队、满血离院 | 床费/扩容价、基础回血速度、药剂倍率与获取、排队是否掉状态、伤员优先级 |

## 6. 餐厅

餐厅是体力见底或需要进食的人排队吃饭的补给区。体验接近「完成订单」：客人点种类，玩家（及厨师工人）做菜上桌。

### 6.1 餐桌

- 餐桌可扩充，**初始 1 张**。
- 没座位的人等桌，与医院等床同构：座位是通量瓶颈。
- 吃完离座，回营地待命。

### 6.2 点餐与上菜

- **每人点想吃的种类**（种类枚举待定，但规则是「点种类」不是点任意自由配方）。
- 玩家像完成订单：做出对应种类的菜，**上桌提交**。
- **保留订单需要的菜再提交**：后厨 merge 会把材料合成掉；对上了当前订单的成品要能留下，禁止系统把「客人正等的那盘」吞进下一次 merge。

### 6.3 菜的效果方向

- 餐厅主职是把人喂完、恢复可派遣状态（体力）。
- 菜可以附带回血，但**高品质菜以短效 buff 为主、回血更少**。
- 低品质 / 对口基础菜：更适合「就是要回状态、把人送走」。
- 高品质菜：更适合出战前的短窗口加成，不当作医院替代品。

具体种类、buff 列表、体力回复公式另议。

### 6.4 厨师工人

- **厨师是工人**，不是纯 UI 按钮。
- 玩家可**指定偏好加权**：某种菜/食材更常被做出来，用来补当前订单缺口种类。
- 加权改变概率，不保证 100% 指定种类；缺口靠「偏好 + 保留成品 + 玩家选择 merge」共同填。

### 6.5 餐厅已定 / 未定

| 已定 | 未定 |
| --- | --- |
| 桌可扩、初始 1 桌、按种类点餐、玩家做菜上桌、保留订单菜再提交、厨师可加权补缺口、高品质偏 buff 少回血 | 体力公式、上菜时长、桌费、厨师工位数量、buff 具体效果 |

本轮落地（补充未定，已定结论不变）：点餐种类为粥 / 炒饭 / 烤肉；厨师偏好为三菜权重，点某一菜加重。

## 7. 后厨

后厨是餐厅的材料层，玩法骨架是 **两两 merge**。

### 7.1 Merge

- 原材料 **两两 merge** 成 **更高品质** 的食材。
- 合成结果在更高品质档内 **随机**，不是固定「A+A 必出指定 B」。
- 品质上去之后：更适合做高品质菜（短效 buff、少回血），不一定更适合「纯回血/纯填饱」。

### 7.2 与订单的关系

- 后厨产出食材 → 做成菜 → 对照订单上桌。
- 玩家要在「继续 merge 冲品质」和「停手保留订单需要的菜」之间做选择。
- 厨师偏好加权作用在「更容易做出缺口种类」，降低纯随机导致的卡单，但不取消随机。

### 7.3 后厨已定 / 未定

| 已定 | 未定 |
| --- | --- |
| 两两 merge、更高品质、结果随机、高品质菜偏 buff、订单成品可保留 | 材料图鉴、merge 失败/保护、与工坊原料是否打通 |

本轮落地（补充未定，已定结论不变）：品质三档为粗料 / 好料 / 精品；后厨栏上限 12，初始约 6 个粗料；材料种类对齐粥 / 炒饭 / 烤肉；精品再 merge 仍出精品，种类可换。入口在餐厅页内后厨分区，不单独页签。

## 8. 已定决策一览

下面这些不再讨论「要不要做」，只讨论怎么落地。

1. **立项：** 独立新游《补给线》 / Supplyline / Resupply；库 `idea7_supplyline`；**不从属于** `idea5_idle`。
2. **主题：** 为前线战士做后勤（食物、医疗，后续可扩装备）。
3. **视觉：** 皇室战争极卡通（大头圆润、粗描边、高饱和），禁止现代战争写实。
4. **营地是主区域**，含待命区；从营地 **出战** 和 **上工**。
5. **医院、餐厅是补给区域**；补给完成回营地。
6. **工坊取消自动无限上工**；有限派工，做完停，人回营地或体力耗尽进补给。
7. **主循环：** 营地派工/出战 → 体力见底进餐厅 / 打完进医院 → 补给完成回营地。
8. **医院：** 床可扩、占床慢回血、药剂加快、无床排队、满血离院。
9. **餐厅：** 桌可扩（初始 1）、按种类点餐、玩家按订单做菜上桌、订单菜可保留再提交。
10. **后厨：** 原材料两两 merge 成更高品质随机食材；高品质菜主给短效 buff、少回血。
11. **厨师是工人**，可指定偏好加权，更容易做出缺口种类。
12. **落地顺序：** 文档 → 医院 → 餐厅 → 后厨。
13. **设置：** HUD 右上角齿轮打开遮罩面板；四页为统计 / 常规 / 版本 / GM。常规含添加到主屏幕（iOS / 外置浏览器 / 等待引导）与音乐音效本地开关（占位）。版本对照 `version.json` 检查更新，设置钮红点与旁提示，不自动刷新。GM 初始化只清 `idea7Supplyline`，不删 prefs。

## 9. 待定（另议，本文不锁）

这些会直接影响数值手感，但**不阻塞**医院/餐厅/后厨按上述规则开工：

- **战斗：** 出战流程、关卡/波次、伤害与血量公式、胜负结算、伤残如何进医院。
- **工人合玩法：** 同一人既出战又上工的职业/疲劳规则、多工种切换、是否编队。
- **工坊内容：** 工种、配方、有限任务的完成条件与奖励。
- **装备补给：** 作为食物/医疗之后的第三补给，规则未定。
- **经济与扩容价：** 床、桌、药剂、材料获取。
- **种类与 buff 表：** 菜的种类枚举、短效 buff 列表、与出战的具体挂钩。
- **体力公式：** 上工/出战消耗、餐厅回复、见底阈值。
- **表现细节：** 动画、音效、营地小人路径，服从第二节视觉，不另开写实方案。

## 10. 落地节奏

建议严格按层推进，前一层可玩后再加下一层，避免三区同时空转。

| 顺序 | 范围 | 完成标准（玩的到） |
| --- | --- | --- |
| 1. 文档 | 本文 | 区域、循环、医院/餐厅/后厨规则可当实现依据 |
| 2. 医院 | 床、排队、慢回血、药剂加速、满血回营地 | 能把伤员从营地送进医院再接回待命 |
| 3. 餐厅 | 初始 1 桌、点种类、做菜上桌、吃完回营地 | 能把体力见底的人喂完送回营地 |
| 4. 后厨 | 两两 merge、品质随机、保留订单菜、厨师加权 | 能用 merge 和厨师偏好填订单缺口 |

战斗、工坊具体内容、装备补给插在上述骨架稳定之后，不插入医院之前。
